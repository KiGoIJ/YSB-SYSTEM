Логика ведения дел

1. Дело

Любое обращение регистрируется как дело с номером, категорией и контрольным сроком.

2. Материалы

Документы добавляются в локальное хранилище и получают служебную карточку.

3. Проверка

Статусы ведутся через журнал: новая, в работе, ожидание, согласование.

4. Контроль

Отчет формируется по локальному журналу без скачивания оригиналов документов.

Регламент проведения проверок

Карта ведения расследований в УСБ РУ ФСБ.

1. Прием

  • Регистрация сигнала.
  • Неразглашение материалов.
  • Установление источника.

2. Дело

  • Присвоение номера.
  • Установка категории.
  • Контроль сроков.

3. Сбор

  • Приобщение документов.
  • Определение доступа.
  • Связывание с делом.

4. Проверка

  • Получение объяснений.
  • Проверка доводов.
  • Фиксация статусов.

5. Вывод

  • Составление заключения.
  • Предложение мер реагирования.
  • Официальное уведомление.

6. Контроль

  • Контроль исполнения мер.
  • Закрытие производства.
  • Передача дела в архив.

Ограничения безопасности

Без скачивания файлов

Оригиналы файлов не подлежат загрузке на сервер. Доступно только копирование текстовых карточек.

Локальный реестр

Добавленные материалы хранятся на локальном диске в IndexedDB текущего компьютера.

Защита данных

Запрещено публиковать закрытые государственные сведения на открытых хостингах.

Отчетность

Сводная статистика формируется по служебному журналу.
