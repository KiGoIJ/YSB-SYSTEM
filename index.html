Документы

Теперь документы не скачиваются с сайта, а добавляются в локальное хранилище браузера. Найдено: 0.

Как это работает. Вы выбираете файл, система сохраняет его в IndexedDB текущего браузера и показывает карточку. Другие пользователи этот файл не видят. Кнопок скачивания документов нет.

Регламент

Короткая карта процесса УСБ в новой системе.

1. Прием

  • Получить обращение.
  • Не публиковать материалы.
  • Определить источник.

2. Дело

  • Присвоить номер.
  • Назначить категорию.
  • Установить срок.

3. Документы

  • Добавить файлы локально.
  • Указать доступ.
  • Связать с делом.

4. Проверка

  • Собрать объяснения.
  • Проверить доводы.
  • Вести статус.

5. Вывод

  • Оформить заключение.
  • Предложить меры.
  • Уведомить допустимо.

6. Контроль

  • Проверить исполнение.
  • Закрыть дело.
  • Перевести в архив.

Главные ограничения

Нет скачивания

Документы не выдаются через сайт. Карточки можно только копировать как текст.

Нет сервера

Добавленные файлы доступны только в конкретном браузере пользователя.

Нет публичных материалов

Закрытые сведения не размещаются на GitHub Pages.

Отчетность

Сводка формируется по локальному журналу и локальным документам.
